# ☕ Aroma & Grão — Café Gourmet & Padaria Artesanal

Uma aplicação web moderna, elegante e 100% responsiva para a cafeteria e padaria artesanal **Aroma & Grão**. O projeto foi desenvolvido com foco em experiência do usuário (UX), transições suaves, design gastronômico atraente e funcionalidades interativas como cardápio com filtros dinâmicos, agendamento de reservas/pedidos e clube de assinatura.

## 🚀 Demonstração & Recursos

### ✨ Funcionalidades Principais:
- **Hero Section Imersiva:** Apresentação visual de alto impacto com chamadas para ação (CTA) diretas.
- **Cardápio Interativo com Filtros (Tab Filter):** Navegação dinâmica sem recarregamento de página entre as categorias:
  - ☕ Cafés Especiais
  - 🥐 Pães Artesanais
  - 🍰 Confeitaria
  - 🥑 Brunch & Salgados
- **Sistema de Reservas & Pedidos Online:** Formulário interativo para agendar mesas ou encomendar produtos para retirada (*Takeaway*).
- **Clube de Assinatura (Modal VIP):** Modal interativo para captação de membros do clube de cafés mensais.
- **Histórias & Processo de Torra:** Seção institucional apresentando a origem dos grãos e a fermentação natural dos pães.
- **Sistema de Notificação Toast:** Feedback visual instantâneo em JavaScript para ações do usuário (envio de formulários, assinaturas e reservas).
- **Design Glassmorphism & Responsividade:** Header fixo com efeito de vidro fosco e menu hambúrguer para dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas e leves de desenvolvimento web *Front-End*:

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estrutura semântica e acessível.
- **[Tailwind CSS (v3 CDN)](https://tailwindcss.com/):** Framework CSS utilitário para estilização rápida, responsiva e suporte a cores personalizadas.
- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Lógica interativa do cardápio, controle de modais e alertas toast.
- **[Font Awesome (v6)](https://fontawesome.com/):** Biblioteca de ícones vetoriais.
- **[Google Fonts](https://fonts.google.com/):** Tipografias *Playfair Display* (elegância clássica) e *Plus Jakarta Sans* (leitura moderna).
- **[Unsplash API/URLs]:** Fotografias gastronômicas de alta qualidade em alta resolução.
